# سكيلات مشروع «مشروع تخرج رويدا»

عند العمل على هذا المشروع، **اقرأ هذا الملف ثم كل ملفات `.md` الأخرى داخل هذا المجلد** قبل التنفيذ، والتزم بالسكيل المناسب للمهمة.

## الملفات
- `quiet-luxury.md` — تصميم فخامة هادئة (فحمي/ذهبي هادئ/أوف وايت)، RTL. (مرجع أسلوبي للمشروع).
- `a4-magazine-page.md` — سكيل صفحة A4 طولي بأسلوب مجلة/تقرير (بيج فاتح، كروت مدورة، Hero مقوس، عمودين، شريط إحصائيات داكن، جدول، رسوم SVG) — HTML+CSS ذاتي الطباعة/PDF.
- أي ملف `*.md` إضافي يُعتبر تعليمات خاصة بالمشروع ويجب قراءته.

## ملاحظات
- مشروع تخرج رويدا حاليًا: **A4 طولي (Portrait)** في PDF Studio.
- التزم بنفس المحتوى النصي الذي يحدده المستخدم دون حذف أو تلخيص.
