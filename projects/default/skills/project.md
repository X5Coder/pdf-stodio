# Default Project — معلومات عامة

## التعريف
- **Project ID:** `default`
- **المسار:** `projects/default/`
- **الاسم (من project.json):** دليل عملي لإعداد دراسة جدوى متكاملة
- **عدد الصفحات:** 40
- **اللغة:** العربية (`ar`)
- **الاتجاه:** RTL (`rtl`)

## البنية داخل المشروع
- `project.json` — إعدادات المشروع.
- `fonts/` — خطوط هذا المشروع فقط.
- `skills/` — كل سكيلات المشروع بصيغة `.md` (تُقرأ كلها عند العمل على المشروع).
- `pages/pageNN/page.jsx` — كود كل صفحة.
- `pages/pageNN/images/` — صور كل صفحة.

## إرشادات عامة (غير متعلقة بالستايل)
- عند تعديل صفحة، عدّل ملف الصفحة وصورها داخل مجلدها فقط.
- عند إضافة/حذف صفحة، حدّث `project.json` (`totalPages`) وحدّث تسجيل/تحميل الصفحات في نظام التطبيق إذا لزم (حسب آلية التحميل الحالية).
- تأكد أن أي مورد (صورة/خط) مستخدم في الصفحة متاح ضمن سياق المشروع أو المسارات المدعومة.
- الهدف النهائي: صفحات قابلة للمعاينة وتصدير PDF صالح.
