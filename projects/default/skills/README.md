# Skills — default project

عند العمل على مشروع `default`، **اقرأ هذا الملف ثم اقرأ كل ملفات `.md` الأخرى داخل هذا المجلد** قبل البدء في التنفيذ.

## ملفات هذا المجلد
- `README.md` — فهرس وتعليمات تحميل السكيلات.
- `project.md` — معلومات عامة عن المشروع ومتطلبات العمل عليه.
- أي ملف `*.md` إضافي يوضع هنا يُعتبر سكيل/تعليمات خاصة بالمشروع ويجب قراءته.

## قاعدة التنفيذ
- حمّل/اقرأ كل سكيلات المشروع أولاً.
- طبّق المطلوب داخل `projects/default/` فقط ما لم يُطلب تعديل نظام عام.
- حافظ على صلاحية المعاينة وتصدير PDF.
