## ⚡ Quick Start

**1️⃣ Copy the repository link.**

**2️⃣ Open [OpenCode](https://opencode.ai) and pick any free model** (use `/models`).

**3️⃣ Paste the repository link to the agent, then send this fixed prompt:**

```text
Download this project to my local machine, then read the `AGENT.md` file.
https://github.com/X5Coder/pdf-stodio
```

That's it. 🎉

## 🧠 What happens next

- ⚙️ The agent sets up the environment and runs the engine locally.
- 📂 It lists your projects. Open one, or create a new one.
- ✍️ Send the content for each page and it builds it, following your project's `style.md`.
- 📤 Preview live and export a valid PDF.
